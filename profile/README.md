# GripEventsCtl

**An unofficial CLI and MCP server for event apps hosted on [Grip](https://grip.events), for your own networking at events you attend.**

> **Unofficial.** GripEventsCtl is not affiliated with, endorsed by, or supported by Grip. It uses your own attendee session, for your own networking. It is **not** for spam, mass swiping, scraping directories into lead lists, contacting people outside the platform, or any behavior that breaks the platform's terms.

## What is GripEventsCtl?

GripEventsCtl is a command-line tool and a [Model Context Protocol](https://modelcontextprotocol.io) server. It lets you read an event's attendee directory, profiles, chats and schedule from your terminal, or through an AI assistant that you control.

You sign in yourself, in a terminal. The password never passes through an assistant. Reads are free. Showing interest, skipping and sending a chat message are off by default, guarded against repeats, logged, and support `--dry-run`.

The project is at its start. The repository holds the workspace scaffold, and the commands are planned, not built. Nothing is published to npm yet.

```sh
npm install -g gripeventsctl   # planned, not yet published
```
